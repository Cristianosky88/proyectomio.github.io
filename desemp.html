Sin configurar
Pasos rápidos por única vez en Supabase (2 minutos):
  1. Crea un proyecto gratis en supabase.com y abre SQL Editor → New query.
  2. Haz clic arriba en "Copiar SQL de Instalación" (o abre supabase_setup.sql), pégalo y presiona Run.
  3. En Authentication → Users → Add user → Create new user, crea el correo y clave de tus operadores (activando Auto Confirm User).
  4. Copia la Project URL y la clave anon public de Project Settings → API y pégalas arriba (o en js/supabase-config.js para dejarlas fijas en GitHub Pages).
